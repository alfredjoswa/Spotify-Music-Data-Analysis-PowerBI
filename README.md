# Spotify Music Data Analysis and Visualization using Power BI

## Project Overview

This project focuses on analysing Spotify music data using Microsoft Power BI to explore track popularity, artist performance, music genres, release trends, and audio characteristics.

The dashboard transforms raw music data into interactive visualisations, enabling users to identify patterns, compare musical attributes, and gain insights into music trends through data analytics.

## Project Objectives

* Analyse track popularity and streaming performance.
* Identify popular artists and music genres.
* Explore audio characteristics such as danceability, energy, valence, and tempo.
* Examine music release trends across different years.
* Compare tracks based on popularity and audio features.
* Develop an interactive dashboard for effective data exploration.
* Present analytical findings through meaningful visualisations.

## Tools and Technologies

* **Microsoft Power BI** — Dashboard development and data visualisation.
* **Power Query** — Data cleaning and transformation.
* **DAX (Data Analysis Expressions)** — Calculated measures and KPI development.
* **Exploratory Data Analysis (EDA)** — Identifying patterns and trends in music data.
* **Data Modelling** — Organising data for analysis and reporting.

## Dataset Description

The dataset contains Spotify music information and audio features used to analyse track characteristics and performance.

### Key Attributes

| Attribute        | Description                                           |
| ---------------- | ----------------------------------------------------- |
| Track_ID         | Unique identifier for a track                         |
| Track_Name       | Name of the music track                               |
| Artist           | Artist associated with the track                      |
| Genre            | Music genre                                           |
| Popularity       | Popularity score of the track                         |
| Duration_Minutes | Track duration in minutes                             |
| Tempo            | Music tempo measured in beats per minute (BPM)        |
| Danceability     | Measure of a track's suitability for dancing          |
| Energy           | Measure of the intensity and activity of a track      |
| Valence          | Measure of the musical positivity conveyed by a track |
| Streams_Millions | Streaming count represented in millions               |
| Release_Year     | Year the track was released                           |
