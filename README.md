# 🎵 Spotify Music Data Analysis and Visualization using Power BI

## 📌 Project Overview

This project focuses on analyzing Spotify music data using Microsoft Power BI to discover meaningful insights into music popularity, artist performance, genres, and audio characteristics.

The dashboard transforms raw music data into interactive visualizations that help users explore patterns, compare musical attributes, and understand trends in music streaming and popularity.

## 🎯 Project Objectives

- Analyze track popularity and streaming performance.
- Identify popular artists and music genres.
- Explore audio characteristics such as danceability, energy, valence, and tempo.
- Examine music release trends across different years.
- Compare tracks based on their popularity and audio features.
- Create an interactive dashboard for effective data exploration.
- Present analytical findings through clear and meaningful visualizations.

## 🛠️ Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Visualization
- Exploratory Data Analysis (EDA)

## 📂 Dataset Description

The dataset contains Spotify music information and audio features used to analyze track characteristics and performance.

### Key Attributes

| Column | Description |
|---|---|
| Track_ID | Unique identifier for a track |
| Track_Name | Name of the music track |
| Artist | Artist associated with the track |
| Genre | Music genre |
| Popularity | Popularity score of the track |
| Duration_Minutes | Track duration in minutes |
| Tempo | Speed of the music measured in BPM |
| Danceability | Measure of how suitable a track is for dancing |
| Energy | Measure of the intensity and activity of a track |
| Valence | Measure of the musical positivity conveyed by a track |
| Streams_Millions | Streaming count represented in millions |
| Release_Year | Year the track was released |
| Explicit | Indicates whether a track contains explicit content |

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)

- Total Tracks
- Total Artists
- Average Popularity
- Average Danceability

### 2. Track Popularity Analysis

Explore track popularity and compare the performance of different tracks.

### 3. Artist Performance Analysis

Identify artists with strong representation in the dataset and compare track-level performance.

### 4. Genre Analysis

Explore the distribution of tracks across music genres and compare their characteristics.

### 5. Audio Features Analysis

Analyze relationships and patterns involving:

- Danceability
- Energy
- Valence
- Tempo
- Track Duration

### 6. Release Year Analysis

Examine how the distribution of tracks varies across release years.

### 7. Interactive Filtering

Use available slicers and filters to explore tracks by attributes such as genre, artist, release year, and explicit content.
